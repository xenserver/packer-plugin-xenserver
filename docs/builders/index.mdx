# XenServer Builder

The XenServer Packer plugin creates XenServer virtual machine images from ISO installers,
existing VMs or templates, and XVA appliances.

Packer supports the following XenServer builders:

- [xenserver-iso](./xenserver-iso) - Creates a VM from installation media,
  provisions it, and exports the resulting image.

- [xenserver-clone](./xenserver-clone) - Clones an existing VM or template,
  provisions it, and exports the result.

- [xenserver-xva](./xenserver-xva) - Imports an existing XVA appliance,
  provisions it, and exports the updated image.

## How to use this plugin

Copy and paste this code into your Packer configuration to install this plugin,
then run [`packer init`](/packer/docs/commands/init).

```hcl
packer {
  required_plugins {
    xenserver = {
      source  = "github.com/xenserver/xenserver"
      version = ">= 0.1.0"
    }
  }
}
```
